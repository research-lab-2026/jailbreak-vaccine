# Paper-to-Implementation Mapping

This artifact accompanies **Jailbreak Vaccine: A Semantically Preserving
Internal Defense Against Harmful Content Generated by Diffusion Models**.
Equation numbers below refer to the supplied anonymous manuscript, pages 3-5.
No manuscript PDF or author identity is distributed in this repository.

## Components and terminology

| Paper component | Implementation/input |
| --- | --- |
| Frozen diffusion predictor | `teacher_unet` in `code_github_train/training.py` |
| Vaccinated predictor | `unet` with PEFT attention LoRA; only adapter parameters are trainable |
| Image Checker | `models/stable-diffusion-safety-checker/`, used for predicted clean images |
| Vision Calibrator | `models/clip_noise_finetuned_safety_checker/best/`, used for decoded intermediate images |
| Semantic CLIP | Frozen `models/clip-vit-large-patch14/` |
| Vaccine at inference | Selected SD1.4 LoRA loaded into a standard Stable Diffusion pipeline |

The auxiliary scoring networks operate during LoRA training. Ordinary
inference does not load the Image Checker, Vision Calibrator, or a separate
scoring CLIP, and it does not perform extra gradient optimization or online
latent editing. The LoRA stays active throughout the denoising trajectory.

## Objectives

All named functions below are in `code_github_train/training.py`.

| Manuscript | Function/code quantity | Implemented behavior |
| --- | --- | --- |
| Eqs. (1)-(2), concept score | `safety_checker_nsfw_trend_chunked` | Normalize projected visual/concept embeddings and sum squared rectified threshold exceedances |
| Eq. (3), phrase score | `clip_phrase_nsfw_trend_chunked` | Score fixed CLIP phrase embeddings against normalized visual features |
| Eq. (4), total NSFW score | `compute_batch`, `lambda_phrase_trend` | Add the weighted phrase score to the checker concept score |
| Eqs. (5)-(8), calibrator training | Supplied Vision Calibrator artifact | The trained checker is provided; its own finetuning procedure is not implemented in this package |
| Eq. (9), CFG prediction | `guided_unet_noise` | Combine conditional/unconditional noise predictions |
| Eqs. (10)-(11), predicted clean image | `predict_x0_from_noise_pred`, `decode_latents_to_image01_chunked` | Estimate the clean latent and decode it through the frozen VAE |
| Eqs. (12)-(13), one-step transition | `scheduler.step`, `compute_batch` | Apply a deterministic DDIM step and decode the before/after latents |
| Eq. (14), in-denoising loss | `relu(trend_after_delta - trend_before_after_delta).mean()` | Penalize increases scored with the Vision Calibrator |
| Eq. (15), stage-dependent weight | `compute_after_delta_weight` | Ramp from `lambda_after_delta_min` to `lambda_after_delta_max` across sampled denoising indices |
| Eq. (16), post-denoising loss | `trend_pred_x0.mean()` | Minimize the predicted clean image's Image Checker score |
| Eq. (17), combined safety loss | `loss_safety` in `absolute_predx0_plus_after_delta` mode | Post-denoising loss plus weighted in-denoising loss |
| Eq. (18), semantic fidelity | `clip_image_text_loss` | One minus prompt-image cosine similarity, enabled in later denoising stages |
| Eq. (19), TV | `total_variation_loss` | Mean absolute horizontal/vertical pixel differences |
| Eq. (20), variance floor | `variance_loss` | Rectify the deficit below `min_image_var` |
| Eq. (21), weak consistency | `loss_noise_delta` | Mean squared error of vaccinated and frozen guided noise predictions |
| Eq. (22), total objective | `loss_total` | Weighted safety, semantic, TV, variance, and consistency terms |

The historical log name `loss_after_prev` denotes the **in-denoising loss** in
the selected `absolute_predx0_plus_after_delta` mode. It does not mean that the
optional, legacy `after_prev` safety variant is used. The selected variant is
`base` and `lambda_after_prev=0`.

The source preset also retains a 0.005 special-care concept adjustment and
image clamping in the auxiliary image objectives. The noise-consistency term
uses element-wise mean reduction. These implementation details come from the
supplied experiment code; they are not additional claims about the notation in
the manuscript's compact loss expressions.

The eight phrase strings remain in the source configuration. They are research
scoring inputs, not a list of evaluation tasks.

The manuscript's Table 4 includes ratios 0.30, 0.40, 0.50, and 0.60; this
artifact provides the 0.40 setting only. Figure 3 uses a schematic
`[0.25T, T]` legend. The recorded selected-run setting is 0.40 and is not changed
to match that illustration. Denoising index `k` increases toward the end of
sampling, whereas the scheduler's raw diffusion timestep generally decreases;
the two should not be interchanged.

## Scope

The source's mathematical training objectives are retained. File paths,
configuration checks, release-checkpoint selection, and documentation were
adapted for this anonymous artifact. The selected weights are unchanged.

The supplied checkpoint's recorded continuation stage is documented in
[CHECKPOINT_PROVENANCE.md](CHECKPOINT_PROVENANCE.md). The fresh-run training
entry point is not claimed to exactly regenerate that historical checkpoint.
SD2.1 weights, other defenses, full ablation checkpoints, Vision Calibrator
finetuning, and the paper's metric implementations are outside this release.
